Las reglas son el prompt común: valen para todas las piezas que se prueban con ellas. Se elige cuáles en «Reglas», arriba. Lo que cambies se queda en este navegador como borrador y se puede probar antes de guardarlo. Entre llaves van los datos de cada pieza ({pieza}, {titulo}, {autor}, {fecha}, {lugar}, {dentro}, {descripcion}, {hechos}, {relaciones}); entre dobles corchetes, lo que solo sale si la pieza tiene ese dato.
